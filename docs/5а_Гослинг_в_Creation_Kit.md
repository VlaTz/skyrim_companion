# 5а. Гослинг в игре — инструкция для Creation Kit (быстрый путь, ~10 минут)

Цель: свой NPC-компаньон «Гослинг» в `Gosling.esp`. **Внешность и голос берём шаблоном у Эрика**
(Use Traits): лицо, раса, голос `MaleYoungEager` — его, а имя, фракции и поведение — наши.
Личные реплики Эрика (про отца, Рорикстед) к Гослингу не переходят — они привязаны к самому Эрику.
Голос из уст Гослинга (темы-заглушки) — следующий кусок 5б, сейчас не нужен.

Если что-то в CK называется иначе или не находится — пиши, разберёмся.

## 0. Запуск CK через MO2

CK запускаем **через MO2** — тогда сохранённый `.esp` попадёт в MO2.

1. MO2 → значок шестерёнок (Executables) → **+** → *Add from file* →
   `D:\Steam\steamapps\common\Skyrim Special Edition\CreationKit.exe`. Название: `Creation Kit`. OK.
2. Запусти `Creation Kit` из списка MO2. Спросит про распаковку `Scripts.zip` — **Да**.
3. *File → Data…* → отметь только **Skyrim.esm** и **Update.esm** → **OK**.
   Загрузка 1–3 минуты, предупреждения можно закрывать (*Yes to All* / *Cancel*).

## 1. Создать NPC по шаблону Эрика

1. *Object Window* (список слева) → **Actors → Actor**. В поле *Filter* сверху введи `Erik` —
   запомни ID Эрика (что-то вроде `ErikTheSlayer`). Фильтр очисти.
2. ПКМ по списку → **New**.

**Вкладка Traits:**

| Поле | Значение |
|---|---|
| ID | `GoslingNPC` |
| Name | `Гослинг` |
| Short Name | `Гослинг` |
| Unique | ✓ |
| Protected | ✓ (убить может только игрок) |
| **Template** (выпадающий список сверху справа) | ID Эрика из шага 1 |
| **Use Traits** (галочка в блоке Template Data) | ✓ — остальные галочки шаблона **не ставить** |

Раса и голос станут серыми — их берёт шаблон, так и надо.

**Вкладка Stats:** **PC Level Mult** = `1.00`, Calc Min = `1`, Calc Max = `50`.

**Вкладка Factions** (ПКМ → New, найти по названию):

| Фракция | Rank |
|---|---|
| `PotentialFollowerFaction` | `0` |
| `CurrentFollowerFaction` | `-1` |

**Вкладка AI Data:** Aggression — `Aggressive`, Confidence — `Brave`, Morality — `No Crime`,
Assistance — `Helps Friends and Allies`.

**Вкладка Inventory:** *Default Outfit* — любой походный (что-то с `Leather` или `Hide` в названии).
Оружие: ПКМ → New → `IronSword` (и, если хочешь, `HuntingBow` + `IronArrow` ×30).

Нажми **OK**.

**Отношение к игроку** (иначе «Следуй за мной» может не появиться): открой Гослинга снова
(двойной клик) → вкладка **Relationships** → ПКМ → New: Parent NPC = `GoslingNPC`,
Child NPC = `Player`, Relationship Level = **Ally** → OK → OK.

## 2. Поставить в мир

Таверна «Морозный фрукт» в Рорикстеде.

1. *Cell View* → World Space: **Interiors** → найди `RoriksteadFrostfruitInn` → двойной клик.
   (Камера: колесо — зум, Shift+мышь — вращение, пробел+мышь — сдвиг.)
2. Перетащи `GoslingNPC` из *Object Window* в окно рендера на пол. Завис в воздухе — выдели и нажми **F**.

## 3. Сохранить и подключить

1. *File → Save* → **`Gosling.esp`**. Закрой CK.
2. MO2: справа внизу **Overwrite** → ПКМ → **Create Mod** → имя `Gosling`.
   Включи мод `Gosling` слева и `Gosling.esp` на вкладке *Plugins* справа.

## 4. Проверка в игре

1. MO2 → SKSE → загрузи сейв.
2. Отпусти Эрика: поговорить → «Пора нам расстаться» (или похожая фраза).
3. Иди в «Морозный фрукт» (или консоль: `coc RoriksteadFrostfruitInn`).
4. Поговори с Гослингом → **«Следуй за мной»**.

Что проверить:
- лицо нормальное, не тёмное (если тёмное — в CK выдели `GoslingNPC` и нажми **Ctrl+F4**, сохрани);
- имя «Гослинг» по-русски (если кракозябры — напиши, поправим кодировку);
- нанимается, идёт за тобой, в бою кричит голосом Эрика.

Сервис подхватит его сам: плагин видит спутника игрока и не считает его «кем-то рядом».
