# 2026-10-11 — Генерация голоса: XTTS-v2 с эмоциями по референсам из игры

## Что сделали

Компаньон отвечает голосом **Эрика Грозного Убийцы** (тип голоса `maleyoungeager`) с эмоцией,
которую выбирает LLM. Личность — Гослинг (промпт из `docs/Описание персонажа.md`).

```
микрофон (F8) → Whisper → текст → LLM → {"emotion": "...", "text": "..."} → XTTS-v2 → динамики
```

Запуск: `start.bat` (= `python -m companion`). Тест голоса без LLM: `python tools/mic_test.py`.

## Какую модель выбрали и почему

**XTTS-v2 (Coqui), без дообучения**, голос и эмоция задаются референсами — настоящими
репликами Эрика из игры.

Почему она:
- **Одна модель** даёт и голос персонажа, и интонацию. Не нужна цепочка «TTS диктора + конвертер голоса».
- **Эмоции бесплатно**: модель копирует подачу референса. Сердитый референс — сердитая речь.
- **Русский язык** поддерживается из коробки.
- **Без обучения** сходство на слух оказалось достаточным. Дообучение оставили на случай, если
  сходства не хватит — скорость от него не меняется.
- **Ресурсы**: ~2 ГБ VRAM, синтез в ~3 раза быстрее реального времени. Потоковая озвучка —
  первый звук через ~0,36 с (замер на RTX 5060 Laptop без игры).

Минусы, о которых знаем:
- Лицензия весов — Coqui Public Model License: **только некоммерческое использование**.
- Медленнее Piper (~0,1 с), но с потоковой озвучкой разница почти не слышна.
- `coqui-tts` 0.27 несовместим с `transformers` 5.x — закреплено `transformers<5`.
- Coqui читает wav через `torchcodec`, которому нужен системный FFmpeg; подменили чтение на
  `soundfile` (`companion/voice/xtts.py`), FFmpeg не нужен.

## Что пробовали и отказались

1. **Piper + RVC.** Piper озвучивает текст голосом диктора, RVC (обучили в Applio на 60 мин
   реплик Эрика) перекрашивает тембр. Работало, но: две модели вместо одной, интонация остаётся
   ровной интонацией Piper — эмоций нет. Обучение остановили на 63-й эпохе, код и модели удалили.
   - Попутно выяснили: в Applio 3.6.5 флаг `--save-every-weights` *выключает* сохранение;
     в bf16 логируемый mel loss завышен (~28 против ~21,5 в fp32) — артефакт измерения, а не
     порча весов.
2. **Дообучение Piper на голосе Эрика.** Возможно, но Piper по устройству «монотонный» —
   эмоций всё равно не будет.
3. **Speech-to-speech модели (одна модель на всё).** Нельзя задать свой голос, игре нужен текст
   (субтитры, команды, память), локально тяжёлые.

## Как работает

### Данные из игры
- `tools/extract_voices.py` — достаёт реплики типа голоса из `Skyrim - Voices_ru0.bsa`
  (`.fuz` → аудио xWMA → wav через PyAV). Для `maleyoungeager`: 2394 реплики, 137 мин.
- `tools/extract_dialogue.py` — для каждой реплики находит запись INFO в `Skyrim.esm` и DLC:
  **метку эмоции** (TRDT: neutral, anger, fear, happy, sad, surprise, puzzled, disgust) и её силу,
  а также **русский текст** из `skyrim_russian.ilstrings` (в `Skyrim - Interface.bsa`).
  Сопоставлено 2334 из 2394; оставшиеся 60 — «осиротевшие» файлы, вырезанные из игры диалоги.
  Результат: `datasets/maleyoungeager/metadata.csv`.

### Голос персонажа
- `tools/make_voice_refs.py` — на каждую эмоцию берёт 3 реплики с самой высокой силой эмоции,
  длиной 4–10 с, без боевых криков и песен, и кладёт в `characters/gosling/voice/<эмоция>/`.
  Неудачный референс можно удалить или заменить своим wav.
- При старте XTTS для каждой эмоции один раз считает условие голоса (GPT-латент + эмбеддинг
  диктора). Дальше синтез только подставляет нужный пресет.

### Эмоции и LLM
- LLM — любой сервер с OpenAI-совместимым API (LM Studio, Ollama, OpenRouter), настройки в
  `config.yaml → llm`. Выбрали универсальный клиент, чтобы не привязываться к провайдеру.
- К промпту личности (`characters/gosling/prompt.md`) добавляется требование отвечать JSON-ом
  `{"emotion", "text"}`. Ответ без JSON или с неизвестной эмоцией не ломает цепочку —
  озвучивается как `neutral`.
- Список эмоций — `companion/emotions.py`, коды совпадают с метками игры.

### Код
| Файл | Что делает |
|---|---|
| `companion/voice/service.py` | цепочка целиком, push-to-talk |
| `companion/voice/xtts.py` | XTTS: пресеты эмоций, синтез, потоковая озвучка |
| `companion/voice/stt.py` | Whisper (faster-whisper) |
| `companion/llm.py` | клиент LLM, история последних 10 обменов |
| `companion/server.py` | HTTP API: `/stt`, `/tts` (с эмоцией), `/chat`, `/events` |
| `tools/mic_test.py` | тест голоса без LLM, эмоция выбирается вручную |

## Открытые вопросы
- Замер VRAM и задержки **с запущенным Скайримом** (оценка: игра ~4 ГБ + XTTS ~2 ГБ + Whisper ~1 ГБ на 8 ГБ).
  Если не влезет — Whisper на CPU.
- Ответ LLM пока не потоковый: озвучка начинается после полного ответа.
- `{memory}` и `{game_context}` в промпте — заглушки до подключения мода.
