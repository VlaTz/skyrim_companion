## Чего хотим

Не болталку, а спутника, который:
1. **сам заговаривает** — реагирует на происходящее, а не только отвечает на вопросы;
2. **помнит мир** — где были, что случилось, куда идём, о чём договорились;
3. **действует** — следует, ждёт, ведёт, подбирает, сражается;
4. **уходит исследовать** и возвращается с рассказом.

## Что реально, а что нет

| Что | Как | Ограничение |
|---|---|---|
| Сам заговаривает | Плагин шлёт события, мозг на событие или тик решает: сказать или промолчать | Задержка LLM+TTS 3–5 с — в бою звучат родные боевые реплики голоса, LLM — вне боя |
| Помнит мир | Места, события, цели в SQLite; при входе в локацию — воспоминания о ней | Знает только то, что прислал плагин; «видеть» картинку — позже, через скриншоты |
| Действия | Пакеты ИИ NPC (Papyrus/SKSE) + обратная связь «получилось/нет» | Тактику боя ведёт ИИ игры |
| «Веди» | Сам выбирает ближайшее интересное место и ведёт игрока | Всё рядом с игроком — просчитывается полностью |
| «Отпусти исследовать» | Реальное путешествие к реальному месту, возвращение с рассказом по данным игры (тип места, враги), с добычей, отметкой места на карте игрока | Вдали от игрока движок не просчитывает бои и находки — приключение **рассказывается**, а не происходит |

## Решения

| Решение | Почему |
|---|---|
| Память — **SQLite** (`data/memory.db`), без Docker/Postgres | Один пользователь, мало данных, ничего не нужно запускать перед игрой. Поиск по смыслу — потом через `sqlite-vec` |
| **Липсинк не нужен** | Не важно для пользователя; без `.lip` NPC говорит, просто не двигает губами |
| Протокол игра → сервис: **JSON по HTTP** `POST /game/event` | Плагину нужен только HTTP-клиент (WinHTTP, без зависимостей); проверять можно без игры (`tools/fake_game.py`) |
| Плагин шлёт **снимок состояния** (`status`) раз в несколько секунд + **разовые события** | Сервис сам замечает изменения (сменилась локация, упало здоровье) — плагин проще |
| Сначала голос из **динамиков сервиса**, голос из уст NPC — отдельным куском | Мост событий и озвучка NPC — две независимые задачи; первая даёт результат быстрее |
| Mantella — не ставим, читаем как пример озвучки NPC | Основа не подходит (разговоры, без автономии), но механизм озвучки решён |
| Проектирование мозга и памяти — по ходу, на реальных событиях | Без данных из игры подробный проект — гадание |
| Графовый RAG для памяти — **не сейчас** (2026-10-17) | Вопросы короткие и про одно, `recall` справляется; связи «кто где живёт, что где» уже точные — из файлов игры, а граф, построенный моделью, внёс бы её ошибки; объём мал. Если `recall` начнёт промахиваться — сначала индекс по сущностям и гибридный поиск (эмбеддинги) |

## Грабли
- **Квесту «стартует с игрой» с диалогами нужен `Seq\<плагин>.seq`** (массив uint32 FormID таких квестов,
  с индексом мода как в файле). CK/xEdit делают его сами, наш сборщик — теперь тоже. Без него квест числится
  запущенным, а его реплики молча не играют, пока квест не перезапустить.
- **`TESNPC::GetObjectVoiceType()` на 1.7.104 возвращает мусор** (`E000007F` при любом голосе) — видимо, сдвиг
  таблицы виртуальных методов. Не верить ему; тип голоса читать полем `voiceType`.
- **Лог Papyrus при запуске через MO2 не создаётся**, хотя `bEnableLogging=1` в INI профиля (проверили, вернули
  как было). Обход: свои нативные функции для скрипта (`GoslingVoice.Log`) → лог SKSE-плагина.
- **heredoc в Bash-инструменте съедает `\\`** в Python-коде — правки с обратными слэшами делать через Edit или
  отдельный файл-скрипт.
- **Функции игры «по адресу» (Address Library) на 1.7.x — риск падения**: часть адресов в 1.7 другая или
  отсутствует. Правило: читаем данные в памяти (поля, виртуальные методы), а не зовём `REL::Relocation`-функции
  без нужды. Обошли так: текст журнала — из `.dlstrings` в сервисе, цена предмета — базовая, инвентарь — `noInit`,
  `Say` — через Papyrus.
- **MO2 и файлы, созданные во время игры**: виртуальная папка `Data` строится при запуске — новые файлы мода
  игра не увидит. Файлы голоса должны существовать заранее; сервис их перезаписывает.
- **MO2: запись SKSE переименовалась в «Creation Kit»** (бинарник по-прежнему `skse64_loader.exe`), а пункт
  «Skyrim Special Edition» запускает игру без SKSE → плагин не грузится, сервис ничего не получает.
  Признак: `getskseversion` — not found, `SkyrimCompanion.log` не обновляется. Вернуть записи название `SKSE`.
- **OpenRouter + Claude Haiku 5.5 по умолчанию «размышляет»**: 170–275 токенов из `max_tokens: 300` уходят на
  скрытые рассуждения → ответ обрезан или пустой, +1–2 с задержки. Лечится `llm.extra_body:
  {reasoning: {enabled: false}}`. При смене модели/сервера проверять `usage.reasoning_tokens`.
- **Обстановку игры — в последнее сообщение, не в системный промпт**: иначе модель повторяет свои прошлые
  ответы («мы в диких землях», хотя уже в хижине). В историю обстановка не пишется.
- **Граница локации дёргается** (вошли/вышли за 2 с) — уход в дикие земли засчитываем после 8 с вне локации.
