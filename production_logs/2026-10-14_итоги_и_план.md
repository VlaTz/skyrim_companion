## Что это

**Гослинг** — ИИ-компаньон в Skyrim SE 1.7.104: NPC в игре, говорит голосом Эрика Грозного Убийцы (XTTS-v2) из своих
уст, слышит игрока (F8 → Whisper) и NPC вокруг, сам заговаривает, помнит прохождение. Личность — `characters/gosling/
prompt.md` (весёлый молодой норд, бывший картограф). Игрок — Владос; обращения: «Владос», «братан», «бро» (не «друг»).

## Как устроено

Наглядно, с подробностями по каждой части, — `docs/Гослинг_схема.html` (интерактивная схема, открыть в браузере).

```
Игра (SKSE-плагин skse_plugin/, C++ CommonLibSSE-NG)
  ├─ POST /game/event: status (раз в 5 с), события, карта, квесты, инвентарь, профиль, реплики NPC, статистика
  └─ GET /game/commands (долгий опрос): «скажи реплику» -> Papyrus GoslingVoice.SayLine -> Actor.Say()
Сервис (companion/, Python, FastAPI, start.bat)
  F8 -> Whisper -> LLM (OpenRouter, Claude Haiku 5.5, JSON {emotion, text, remember?}) + справки-инструменты
     -> XTTS -> .wav + .lip в мод Gosling -> команда say -> Гослинг говорит в игре (иначе — колонки)
  Мозг (сам заговаривает), память (SQLite), летописец (дневник), трасса (logs/trace)
```

## Главные решения (почему так)

| Решение | Почему |
|---|---|
| XTTS-v2 без дообучения, эмоции — референсы по меткам диалогов Скайрима; `puzzled` выключен; темп 1.2 | одна модель — и голос, и эмоции; puzzled плохо звучит; 1.0 медленно |
| Голос из уст NPC: темы-заглушки + `Say()` через Papyrus, файлы перезаписываются (MO2) | как Mantella; без функций игры по адресу |
| Функции игры «по адресу» на 1.7.104 — избегаем; читаем поля, события, Papyrus, Scaleform | часть адресов/vtable в 1.7.x другие (`GetObjectVoiceType` даёт мусор) |
| Гибрид контекста: текущее место/обстановка — автоматически, остальное — справками | частое — мгновенно, редкое — по запросу (+1–1,5 с на справку) |
| **Правим описания инструментов, а не промпт персонажа и не код-подпорки** | решение игрока 2026-10-14 (случай с сумкой) |
| Говорить ли самому — решает модель: interest 0–10 на любой повод, видя свою последнюю реплику; говорит при ≥ `brain.interest` | разговорчивость — одной цифрой; паузы (60/25/20 с) и шансы по типам событий убраны 2026-10-14 — глотали важное |
| Память строго по сейву (старый сейв — «будущее» в архив, и разговоры тоже) | решение игрока; архив не стирается |
| Справка о местах и профиль — из данных игры, а не генерацией | точные данные, выдумывать нечего |
| Базовые знания о лоре есть с начала, дополняются по ходу | решение игрока 2026-10-14 |
| Гибель Владоса Гослинг знает прямо (не «сон», не «дежавю»): говорит о ней с шуткой и советом | решение игрока 2026-10-15 |

## Грабли (самое важное; полный список — в плане реализации)
- **Квест «стартует с игрой» с диалогами требует `Seq\<плагин>.seq`**, иначе `Say()` молча не звучит.
- **MO2 строит виртуальную `Data` при запуске:** файлы мода должны существовать заранее (заглушки .wav/.lip/.seq).
- **LipGenerator** не берёт тишину и фразы < 1 с (код 1) — добиваем до 1 с; знает только английский — текст не даём.
- **Сразу после фразы `Say()` отбрасывается** — плагин повторяет, пока звук не пошёл.
- **HUD берёт текст субтитра при появлении** — подмена в `SubtitleManager` не видна; показываем через `ShowSubtitle`.
- **Ранг −1 во фракциях** ставят и настоящим, и «запасным» (Хронгар во фракции ярла) — правило в `places.py`.
- **HearthFires переопределяет запись Вайтрана** — жители в `ACUN`, собираем из всех версий записи.
- **Модель держится своих прошлых слов:** отказ в истории разговора повторяется (уходит через 10 обменов).
- **Bash-инструмент: heredoc съедает `\\` и `\n`** в Python — правки с обратными слэшами через Edit или файл-скрипт
