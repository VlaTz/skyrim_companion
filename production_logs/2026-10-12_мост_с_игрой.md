# 2026-10-12 — Мост с игрой: исследование и решения

Кусок 0 плана (`2026-10-12_план_реализации.md`). Как делать SKSE-плагин под Skyrim 1.7.104 и как
заставить NPC говорить сгенерированным голосом — по исходникам Mantella и CommonLibSSE-NG.

## Решения

| Решение | Почему |
|---|---|
| **Свой SKSE-плагин** на `alandtse/CommonLibSSE-NG` (ветка `ng`) | Единственная живая библиотека с поддержкой 1.7.104 (`RUNTIME_SSE_1_7_104`, релиз v12.1.0 от 2026-10-11). Старые сборки (CharmedBaryon, colorglass-vcpkg) на 1.7.x могут падать: в 1.7.99 сдвинулись поля `PlayerCharacter`, сменились часть адресов |
| Шаблон `libxse/commonlibsse-ng-template` (**xmake** 3.0+, C++23) | Рекомендованный шаблон, уже указывает на нужную ветку `ng` |
| Готовый `SKSE_HTTP` (Mantella) — **не берём** | Собран на старой библиотеке, работа на 1.7.104 не подтверждена нигде |
| События — прямо из C++ (без Papyrus), HTTP — в отдельном потоке | Подписка на события движка надёжнее и быстрее Papyrus; игровой поток не блокируем |
| Код Mantella (Python) **не копируем** | Лицензия AGPL-3.0. Игровая часть `Mantella-Spell` — MIT, оттуда можно брать Papyrus-приёмы |
| Плагин будет под **GPL-3.0** | Так требует CommonLibSSE-NG. Python-сервис — отдельная программа, его не касается |

## Какие события брать (CommonLibSSE-NG)

| Что | Класс | Откуда |
|---|---|---|
| Смена локации | `TESActorLocationChangeEvent` (oldLoc/newLoc — `BGSLocation*`) | `ScriptEventSourceHolder`, фильтр: актёр = игрок |
| Смена ячейки | `BGSActorCellEvent` | `PlayerCharacter::AsBGSActorCellEventSource()` |
| Бой | `TESCombatEvent` | `ScriptEventSourceHolder`, игрок — актёр или цель |
| Смерть | `TESDeathEvent` | `ScriptEventSourceHolder` |
| Попадания | `TESHitEvent` | `ScriptEventSourceHolder` |
| Меню | `MenuOpenCloseEvent` | `UI::GetSingleton()->AddEventSink` |
| Загрузка/новая игра | `kPostLoadGame`, `kNewGame`, `kDataLoaded` | SKSE Messaging |
| Здоровье, время, погода, кто рядом | события нет — опрос по таймеру в игровом потоке | → `status` раз в несколько секунд |
| Позже | `TESContainerChangedEvent` (добыча), `LocationDiscovery::Event` (открыто место), `TESQuestStageEvent` | |

## Как Mantella озвучивает NPC (для куска 5)

- В `.esp` — **две** темы диалога по одной реплике. Перед репликой Python копирует новый `.wav` поверх
  файла с фиксированным именем, и Papyrus вызывает `actor.Say(topic)`.
- **Темы чередуются** (1, 2, 1, …): если одну тему сказать дважды подряд, движок может проиграть старый
  звук из кэша.
- Путь файла: `Sound/Voice/<плагин.esp>/<тип голоса>/<префикс квеста>_<префикс темы>_<FormID реплики>_1.wav`.
- **`.wav` без `.lip` играет** — липсинк просто отключается (у Mantella это настройка).
- Mantella подменяет тип голоса NPC на свой общий. **Нам это не нужно**: у Гослинга сразу будет
  `MaleYoungEager`, файлы кладём в `Sound/Voice/Gosling.esp/MaleYoungEager/`, и родные боевые реплики
  этого голоса сохраняются.
- Конец реплики Mantella отслеживает заклинанием-маркером; Python заодно передаёт длительность фразы.
- Субтитры — отдельный плагин (`Mantella-Subtitles-Plugin-NG`): подменяет текст реплики перед `Say`.
  Нам — позже, можно сделать в своём плагине.
