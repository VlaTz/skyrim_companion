# 2026-10-15 — Интерактивная схема Гослинга

Просьба игрока: зафиксировать на одной схеме все блоки, из которых состоит Гослинг, — с общим видом и видом
отдельного блока, кликом на часть — подробности; всё в одном окне, только HTML, без Python.

**`docs/Гослинг_схема.html`** — один файл, без интернета и библиотек (SVG + JavaScript). Открывается двойным
кликом в любом браузере.

- 16 блоков: игра (SKSE-плагин), мод Gosling.esp, Владос, восприятие, голос и слух, мозг, мыслитель, шутки,
  разговор (модель), личность, справки, память, летописец, знания о мире, инструменты разработки, дальше по плану;
  внутри — части (~70), у каждой статус: работает в игре / сделано, не проверено / в планах.
- Связи между блоками с подписями («поводы», «заговорить ли?», «.wav + .lip → «скажи»»…).
- Тащить мышью, зум колесом и кнопками, щипок на тачпаде/экране; клик на блок — приближает его и открывает
  справа описание, части, файлы и связи (переход по ним кликом); клик на часть — её описание; двойной клик —
  приблизить; Esc / «Общий вид» — всё сразу; поиск подсвечивает части и приближает к первой; светлая/тёмная тема.

Данные схемы — в начале скрипта (`GROUPS`, `EDGES`): блок или часть добавить/поменять статус — правкой там.
Статусы — по логам на 2026-10-15; когда проверим сегодняшнее в игре — перевести «сделано, не проверено» в «работает».

## Вторая версия: Гослинг в центре (по просьбе игрока)

- **В центре — фото Райана Гослинга** (дал игрок), встроено в файл (JPEG ~24 КБ, base64) — схема по-прежнему
  один файл. Клик на фото — общее описание Гослинга и список блоков; двойной клик — общий вид.
- **Блоки — кольцом вокруг** (эллипс), порядок подобран так, чтобы связанные стояли рядом: восприятие → мозг →
  мыслитель → шутки → память → летописец → знания → справки → разговор → личность → голос → Владос → мод → игра →
  инструменты → план. Через центр идут только 2 связи — **стрелки огибают фото дугой**, по лицу не проходят.
- **У каждого блока свой цвет** (оттенки по кругу; инструменты и план — серые): рамка, полоска сверху, лёгкая
  подкраска карточки и частей; в панели — полоска цвета блока у заголовка. Цвета статусов — только на точках.
- Проверено в браузере: кольцо, фото, стрелки в обход, цвета, клик на фото (панель открывается).
- По просьбе игрока центральный круг уменьшен (радиус фото 470 -> 320, подпись мельче).
- Перетаскивание карты больше не выделяет текст страницы (`user-select: none` на карте, `preventDefault` при нажатии);
  клик и двойной клик по блокам работают, как раньше.

## Обзор «Как устроен Гослинг» (по просьбе игрока)

Не хватало общего описания, как работают блоки вместе. Кнопка «Как устроен» в шапке и клик по фото открывают обзор:
- **Гослинг — агент, а не чат-бот:** цикл видит → решает → отвечает (с инструментами, до 3 раз за ответ) → говорит →
  запоминает; названия блоков в тексте — ссылки на них;
- **два пути реплики:** Владос спросил (F8 → Whisper → модель + планировщик справок → голос) и Гослинг заговорил сам
  (повод → мозг → interest → порог → сверка обстановки → голос), с задержками;
- **инструменты:** 6 справок, их вызывает сама модель по описанию; планировщик — быстрый запрос без истории;
- **модели:** Haiku 5.5 — разговор, реплики по своей инициативе, оценка интереса, планировщик справок; Sonnet 5.5 —
  мыслитель, летописец, пополнение шуток; Opus 5.5 — разовая генерация шуток вручную; Whisper large-v3-turbo и XTTS-v2 —
  локально на видеокарте; LipGenerator (из CK) — губы, не нейросеть; знания о мире — поиск, не модель.

- По просьбе игрока: **одинарный клик** по блоку, части или фото — только подробности в панели, масштаб не меняется;
  **двойной клик** — то же и приближение (по фото — к центру). Двойной клик распознаём сами (два клика по одному за
  350 мс): `preventDefault` при нажатии (против выделения текста) может гасить у браузера `dblclick`. Ссылки внутри
  панели и поиск по-прежнему приближают к найденному блоку — иначе его не видно.
